# India Retail Pulse

A responsive retail analytics dashboard inspired by common sales-reporting workflows. It is an original frontend project and does not reuse the linked Power BI report or its dataset.

## Run locally

Open `index.html` in a modern browser. No build step, package installation, or server is required.

## What’s included

- Overview, Sales trends, Products, and Customers views
- INR formatting and Indian-number grouping (₹, lakh, crore)
- Date-range, state, and category filters
- KPI cards, sales/profit trend, category and channel breakdowns, regional view, and ranked tables
- CSV export for the currently filtered orders
- Responsive layout for desktop, tablet, and mobile

## Data note

The app generates a deterministic, illustrative demo dataset in the browser. Names, orders, ratings, sales, and all displayed insights are synthetic and should not be treated as actual business results. Edit the product and state lists in `app.js` to customize the demo.
